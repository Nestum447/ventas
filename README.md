# 📊 Carpio Enterprises - Registro Diario de Ventas

Este proyecto es una aplicación en **Python + Streamlit** para registrar y consultar ventas diarias de productos.  
La información se almacena en una base de datos **SQLite (`ventas.db`)** para garantizar persistencia de datos.

---

## 🚀 Características

- Registro de ventas con:
  - Fecha de la venta  
  - Nombre del producto  
  - Cantidad vendida  
  - Precio unitario  
- Almacenamiento en **SQLite**.  
- Historial de ventas mostrado en tabla interactiva.  
- Base de datos creada automáticamente al iniciar la aplicación.
